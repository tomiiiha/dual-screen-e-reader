# v0.2.0-alpha — Working Reader Prototype (Draft)

CrossPoint is running on the custom ESP32-S3 setup with a GDEH0576T81 E Ink display, SPI microSD breakout, and ANO navigation controller.

## Changes

- Got the main menu and library working on the custom hardware.
- Confirmed that the SD card can mount and list files with the display and controls attached.
- Added Back navigation using the ANO rotary encoder on GPIO 18 and 21.
- Found a workaround for inverted text refreshes: turn off text anti-aliasing.

## Still to do

- Investigate the grayscale rendering problem in the custom display driver.
- Check SD initialization over repeated boots; the earlier startup failure is not yet explained.
- Test ordinary EPUBs and longer reading sessions.
- Add sleep/wake and battery power support.
- Move beyond the breadboard and design an enclosure.

This is a draft for a future release, not a claim that the prototype is ready for daily use.
