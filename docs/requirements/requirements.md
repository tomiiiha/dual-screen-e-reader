PORTABILITY
- Must be practical to carry every day
- Must protect both e-paper panels when closed

DISPLAY
- Two separate e-paper displays
- Approximately book like two page reading experience
- Adjustable lighting for reading at night. Built-in frontlight would be nice, but a small gooseneck lamp is another possibility.

INPUT
- Physical controls
- No touchscreen in initial design

MECHANICAL
- Folding enclosure
- Transparent/translucent housing preferred
- Housing will be 3d printed due to cost / lack of access to services

SOFTWARE
- Local ebook storage (EPUB preferred)
- Simple reading/navigation interface
- Existing open source software intended, I do not wish to create my own
- Modify existing open source software

DESIGN PHILOSOPHY
- Original hardware/product design
- Inspiration from several sources, but not 1:1 copy
- Avoid unnecessary complexity
- Document important engineering decisions
